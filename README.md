# OpenFL Display API for Stencyl

[Website/Releases](http://www.polydes.com/repo/engine/openfl.display) |
[Issues](https://github.com/polydes/openfl.display/issues)

</div>

This [Stencyl](https://www.stencyl.com/) extension wraps the [openfl.display](https://api.openfl.org/openfl/display/) API for use as design mode blocks.

## Using this Stencyl extension

This is a free extension. Installation instructions and guides can be found [here](http://www.polydes.com/repo/engine/openfl.display/).
